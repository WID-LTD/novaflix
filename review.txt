# OpenCode Prompt — Redesign NovaFlix into a Premium Streaming Platform

## Project Overview

You are an expert Senior Product Designer, UI/UX Designer, and React Frontend Engineer.

Redesign the entire UI/UX of the existing NovaFlix application without breaking its existing functionality or API integrations.

This is **not a refactor of functionality**. It is a complete redesign of the user experience, visual identity, information architecture, component system, and interaction design while preserving the current business logic.

The final product should feel like a premium streaming platform comparable to Netflix, Apple TV, Disney+, HBO Max, and Prime Video, while maintaining its own unique identity.

---

# Primary Goal

Transform NovaFlix into a world-class cinematic streaming experience that emphasizes:

* Beautiful UI
* Exceptional UX
* Fast navigation
* Modern interactions
* Accessibility
* Responsive layouts
* Smooth animations
* Premium visual hierarchy

Every screen should feel polished enough to be used in production.

---

# Design Philosophy

Follow these principles:

* Content First
* Minimal but Premium
* Cinematic Experience
* Large Visuals
* Smooth Motion
* Clean Typography
* Spacious Layout
* Consistent Design System
* High Accessibility
* Responsive by Default

Avoid clutter.

Avoid excessive gradients.

Avoid outdated card layouts.

Avoid inconsistent spacing.

5. Improved navigation and information architecture.
6. Consistent spacing, typography, colors, and visual hierarchy across the entire application.
7. A premium streaming experience that rivals leading entertainment platforms while retaining NovaFlix's existing functionality.
